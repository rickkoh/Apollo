- hub: hub actor, store, websocket server, hub-dev and the voice channel plugin

- panel: offer the cv-panel line when an editor uses another wrapper
- ui: name the app apollo in the sidebar and the tray's open item
- channels: apollo dev runs beside the stable app with its own data, cv-dev launcher and bottom-left overlay
- updates: check the gitlab feed with a keychain deploy token, offer and install updates, open at login
- updates: releases and the update feed move to public github releases, so updates need no token
- app: voice bridge is now apollo: app name, bundle id, marketplace, approval file and variables
